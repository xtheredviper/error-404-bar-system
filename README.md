"Welcome to the **ERROR 404** Mainframe, Edgerunner." 🦾

This project is a terminal-based order management system for the **ERROR 404** bar. It was built to simulate a futuristic interface, ensuring a seamless purchasing experience even in a "high tech, low life" environment.

## 📝 Features

- **ERROR 404 Menu:** Exclusive items such as the *Mainframe Burger* and *Glitch Sour*.
- **Smart Search:** The system locates products in the database regardless of case sensitivity (uppercase/lowercase).
- **Transaction Validation:** Protection against invalid inputs and null quantities.
- **Themed Interface:** Visual feedback and personalized messages tailored for the cyberpunk atmosphere.

## 🧠 Core Concepts Applied

* **Flexible Search:** Iteration over dictionary keys to ensure the customer's order is found despite typing variations.
* **Data Handling:** Use of `None` for state control and string sanitization with `.strip()` and `.lower()`.
* **Exception Handling:** Implementation of `try-except` blocks to catch value errors and keep the system operational.
* **Dictionary Logic:** Nested structures for categories and data flattening for fast price lookups.
