# ⚡ ERROR 404: Gestão de Pedidos Cyberpunk

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![Theme](https://img.shields.io/badge/tema-cyberpunk-bc00ff?style=for-the-badge)

"Bem-vindo ao Mainframe do **ERROR 404**, Edgerunner." 🦾

Este projeto é um sistema de gerenciamento de pedidos via terminal para o bar **ERROR 404**. Ele foi construído para simular uma interface futurista, garantindo que a experiência de compra seja fluida, mesmo em um ambiente de alta tecnologia e baixa vida.

## 📝 Funcionalidades

- **Cardápio do ERROR 404:** Itens exclusivos como *Mainframe Burger* e *Glitch Sour*.
- **Busca Inteligente:** O sistema encontra os produtos no banco de dados independente de letras maiúsculas ou minúsculas.
- **Validação de Transações:** Proteção contra entradas inválidas e quantidades nulas.
- **Interface Temática:** Feedback visual e mensagens personalizadas para o ambiente cyberpunk.

## 🧠 Conceitos Aplicados

* **Busca Flexível:** Iteração sobre as chaves do dicionário para garantir que o pedido do cliente seja encontrado mesmo com variações de digitação.
* **Tratamento de Dados:** Uso de `None` para controle de estado e sanitização de strings com `.strip()` e `.lower()`.
* **Tratamento de Exceções:** Implementação de `try-except` para capturar erros de valor e manter o sistema operacional.
* **Lógica de Dicionários:** Estrutura aninhada para categorias e achatamento de dados para busca rápida de preços.
